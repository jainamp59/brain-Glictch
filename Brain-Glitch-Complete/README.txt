BRAIN GLITCH - VS CODE + XAMPP SETUP

1. Extract this folder into:
   C:\xampp\htdocs\Brain-Glitch

2. Start XAMPP:
   - Apache
   - MySQL

3. Open phpMyAdmin:
   http://localhost/phpmyadmin

4. Import:
   database/brain_glitch.sql

5. Open the game:
   http://localhost/Brain-Glitch/

IMPORTANT:
- Live Server is fine for the front-end demo, but PHP leaderboard requires Apache/XAMPP.
- If MySQL root has a password, edit php/db.php.
- Game files are in index.html, css/style.css, js/game.js.
- PHP API files are in php/.
- There are 20 levels in js/game.js.
